Embedded 2D Video Game (Mbed, C)

I built a complete embedded 2D video game in C using the Mbed platform, developing everything from the core game loop and hardware input handling to the visual system and gameplay mechanics. I implemented player movement, scoring, lives, power-ups, teleportation, and win/lose conditions, all running on constrained embedded hardware.

The game world is stored using a custom hash-table–based map system, and I designed and rendered all sprites manually, handling limited visibility, screen updates, and performance constraints on a small uLCD display. This project combined low-level systems programming with game logic, data structures, and custom graphics to deliver a fully playable handheld game.

  • Custom game loop with hardware button input and sprite rendering on uLCD.
  • Hash-table map storage, power-ups, teleportation, and win/lose logic.
  • Manual sprite design and optimized drawing for constrained hardware.
